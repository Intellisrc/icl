Package: com.intellisrc.web.service.session

[Groovy] Class RedisSession

              • com.intellisrc.web.service.session.RedisSession 
              • @groovy.transform.CompileStatic
class RedisSession
extends AbstractKVSessionStore

                Persists the sessions into a Redis server (com.intellisrc.etc.Redis), so they survive a restart of the WebService. The Redis server is configured with redis.host and redis.port, and the session keys are grouped under the prefix specified by web.session.redis.prefix (default: "web.sessions"). NOTE: the values stored as session attributes must be Serializable to be able to survive a restart.
