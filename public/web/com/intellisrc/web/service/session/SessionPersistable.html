Package: com.intellisrc.web.service.session

[Groovy] Interface SessionPersistable

  • @groovy.transform.CompileStatic
interface SessionPersistable
extends org.eclipse.jetty.session.SessionDataStore

    Common contract for the stores used to keep the sessions of a WebService. It preserves the important method declarations of FileSessionDataStore (Jetty), so that implementations extending it (like FileSession) are almost trivial, while other implementations (like BerkeleySession or RedisSession) can be built on top of any key-value backend. To add a new implementation, extend one of the Jetty base classes (NullSessionDataStore, FileSessionDataStore or ObjectStreamSessionDataStore) and implement this interface, then assign it to WebService.sessionType (or select it with web.session.type).
