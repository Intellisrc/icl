Package com.intellisrc.web.service.session

  • Interface Summary 
    Interface Description
    SessionPersistable Common contract for the stores used to keep the sessions of a WebService.
  • Class Summary 
    Class Description
    AbstractKVSessionStore Base class to persist the sessions into any key-value store.
    BerkeleySession Persists the sessions into a BerkeleyDB key-value store (com.intellisrc.etc.BerkeleyDB), so they survive a restart of the WebService.
    FileSession Persists the sessions as files in a directory (using the Jetty FileSessionDataStore), so they survive a restart of the WebService.
    MemorySession Keeps the sessions in memory only (Jetty default behavior).
    RedisSession Persists the sessions into a Redis server (com.intellisrc.etc.Redis), so they survive a restart of the WebService.
