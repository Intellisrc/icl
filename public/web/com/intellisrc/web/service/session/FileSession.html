                SessionPersistable
                @groovy.transform.CompileStatic
class FileSession
extends org.eclipse.jetty.session.FileSessionDataStore
implements SessionPersistable

                Persists the sessions as files in a directory (using the Jetty FileSessionDataStore), so they survive a restart of the WebService. The directory can be specified with web.session.dir (default: ".sessions"). Each running WebService instance must use a different directory. NOTE: the values stored as session attributes must be Serializable to be able to survive a restart.
