[Groovy] Class TrustedProxies

    • com.intellisrc.web.service.TrustedProxies 
    • @groovy.transform.CompileStatic
class TrustedProxies
extends java.lang.Object

      List of trusted proxies used to decide when the X-Forwarded-For header can be trusted to calculate the client IP (see Request.ip()). The proxies can be specified as String (IP address, hostname, CIDR annotation like "10.0.0.0/8" or ranges like "10.0.0.1-100"), InetAddress or Network objects (or a mix of them, including nested collections). Hostnames are resolved only once, when the list is created.
